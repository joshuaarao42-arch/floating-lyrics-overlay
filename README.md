# floatinf-lyrics-overlay

A desktop lyrics visualizer made with Python and Tkinter.

## Features
- Floating lyric windows
- Typewriter animation
- Fade-out effect
- Random screen positioning
- Smooth upward drifting animation

## Requirements

- Python 3.10+
- Tkinter (included with most Python installations)

## Run

```bash
python lyrics_visualizer.py
```
